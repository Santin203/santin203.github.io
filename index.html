About

My work sits where software engineering meets data: writing the systems that move information, and the code that makes sure it's right.

At Fujitsu I built an internal web app on AWS Amplify, React and Cognito with a serverless backend (Lambda, DynamoDB, API Gateway), plus monitoring and search through CloudWatch and OpenSearch. More recently at Intego Group I moved into clinical data, programming in SAS and R against CDISC standards (SDTM, ADaM) and producing Tables, Listings & Graphs with the pharmaverse ecosystem.

Along the way I've learned that the unglamorous parts, such as validation, documentation and quality control, are what make a project trustworthy. I pick up new tools quickly and I enjoy explaining technical things clearly to people who aren't technical.
